# 逐帧输入脚本（.tas）

打开播放器（`tas_player.bat`）会有两个窗口：主窗口（走帧、状态面板）和“输入脚本”窗口。
脚本文件放在 `runs\`，边改边自动保存。脚本窗口关掉只是隐藏，主窗口的“脚本窗口”按钮可以再叫出来。

## 一行就是一帧

脚本窗口里每一行是一帧，左边一栏是帧号。接管游戏的那一刻是第 0 帧，第 1 行是第 1 帧。

```
S W          # 第 1 帧：同时按住 S 和 W
S W          # 第 2 帧：继续按住
J            # 第 3 帧：只按 J

K            # 第 5 帧（上面的空行是第 4 帧，什么都不按）
```

- 键名之间用空格或逗号隔开，不分大小写。
- 一个键要按住几帧，就连着几行都写它；哪一行没写，那一帧就松开。
- 空行就是这一帧不按任何键。
- `#` 后面是注释，可以写在键名后面；整行都是注释的行不占帧。
- 脚本最后一行之后的帧什么都不按。

## 快速写很多帧

写 `5 S` 再换行（或把光标移到别的行），它会自动列成 5 行 `S`；写 `5` 则是 5 行空行。
正在打字的那一行不会被改动，光标离开后才展开。要按数字键时写成 `1 5`（1 帧，按 5）。

点下面还没写的某个帧号所在的行，光标直接落到那一帧，中间的行自动补成空行。

## 播放脚本

按“▶ 播放”或小键盘 `/`：工具接管游戏，从当前帧按脚本以正常速度放到最后一行，然后停在那里。

- 放完之后再按播放：回到第 0 帧，从头重放一遍。
- 放完之后往下接着写：再按播放就从停住的地方接着放新写的部分。
- 播放途中再按一次是暂停。脚本是空的时候，播放就是让游戏一直跑。

## 改脚本时游戏怎么跟

- 蓝底的一行是画面上这一帧用的输入。
- 改了已经放过的行，游戏会自动退回去按新脚本重放到当前帧，画面随即更新。
- 写错的行标红，窗口底部说明哪里错；改好之前游戏继续用上一版脚本。
- 录制（小键盘 `*`）结束后，按过的键会逐帧出现在脚本窗口里，可以直接改。
- 小键盘 `+ - * /` 在任何地方都有效。脚本窗口里也有 ⏮、◀ 1、播放、1 ▶ 四个按钮。

## 键名

字母 `A`–`Z`、数字 `0`–`9`、`F1`–`F15`、`Space`、`Enter`、`Escape`（或 `Esc`）、`Tab`、
`LeftShift`（或 `Shift`）、`LeftCtrl`（或 `Ctrl`）、`LeftAlt`（或 `Alt`）、`RightShift`、`RightCtrl`、
`Up` `Down` `Left` `Right`、`Numpad0`–`Numpad9` 等，完整列表在 `work\keycodes.py`。

脚本里写的是键盘上的键，不是游戏里的动作，所以要按你自己在游戏里设的键位来写。
例如键位是 `Space` 锁定、`J` 挥砍、`K` 跳、`W A S D` 移动时，锁定并挥砍就写 `Space J`。

## 手柄（仅原版 DX9）

手柄的键和键盘的键可以写在同一行，大小写随意：

- 按键：`PadA` `PadB` `PadX` `PadY` `PadLB` `PadRB` `PadBack` `PadStart` `PadL3` `PadR3`、
  十字键 `PadUp` `PadDown` `PadLeft` `PadRight`。
- 摇杆：`PadLS=x/y`（左）、`PadRS=x/y`（右），x 向右、y 向上，范围 −1 到 1。例如 `PadLS=0/1` 是左摇杆推满向上，`PadLS=0.71/0.71` 是右上。
- 扳机：`PadLT`、`PadRT` 是按到底；`PadLT=0.5` 是按一半。

例：`PadRB PadLS=0/1 PadY` = 锁定、推上、挥砍（游戏默认手柄键位：RB 锁定、Y 剑、X 枪、A 跳、B 恶魔之手、LT 油门、LB 魔人）。

播放脚本时手柄由工具接管：一行里没写手柄就当手柄全松开，所以插着手柄误碰也不会混进去。
用手柄打的录制会把这些记号原样写进脚本，摇杆值保留游戏里的精确数值。
扳机和摇杆方向的按键位由工具按手柄自己的死区换算，和游戏的做法一样。
游戏的按住连发标志（auto-repeat）只在按下那一帧置位，菜单里长按自动翻页不会重现。

## 文件里的写法

文件就是脚本窗口里的文字。带帧数的行（`10 Space K`）和旧的绝对帧号写法（`1-4: Space L`）
都能打开，打开后一律显示成一行一帧，编辑时才会改写文件。

## 红刀点（尼禄）

脚本窗口右边一栏，走过的帧会标出红刀窗口：

- 金色“MAX点”：把 Q 写在这一行，红刀槽直接充满 3 格。
- 红色“红刀点”：把 Q 写在这一行，红刀槽 +1 格。
- “★MAX成功 / ★红刀成功”：这一行的 Q 已经生效。

主窗口状态面板同时显示“红刀槽 n/3”和当前帧是不是红刀点。标记来自游戏自己的计时器，改了前面的输入后要重新走一遍才更新。
