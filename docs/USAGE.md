# 使用说明

《鬼泣4》PC Steam 版的逐帧 TAS 工具，支持两个版本，只用于单机游玩：

| 版本 | Steam 应用 | 程序 | 构建号 |
|---|---|---|---|
| 特别版 | 329050 | `DevilMayCry4SpecialEdition.exe` | 24329835 |
| 原版（DX9） | 45700 | `DevilMayCry4_DX9.exe` | 21360 |

原版目录里的 `DevilMayCry4_DX10.exe` 不支持。两个版本用同一套工具、同一个播放器，工具按游戏程序自动选择。

## 一、准备

1. 需要正版 Steam 版游戏，Steam 要开着并登录。
2. 游戏必须是**窗口模式**。全屏时工具不会冻结游戏（冻住的全屏窗口会盖住整个屏幕）。
   - 特别版：游戏里 Options → PC Settings → Full Screen 设成 OFF。
   - 原版：`%LOCALAPPDATA%\CAPCOM\DEVILMAYCRY4\config.ini` 里 `FullScreen=OFF`（先备份原文件）。
3. 安装 [Python 3.13](https://www.python.org/downloads/)（64 位，安装时保留“py launcher”）。
4. 下载本项目：在 GitHub 页面点 Code → Download ZIP，解压到任意文件夹。
5. 双击 `setup.bat`。它会建好 Python 环境并装上需要的组件，需要联网，只用做一次。

游戏装在哪不用填，工具会从 Steam 里自动找。找不到时（比如游戏放在别的文件夹），启动时会弹出窗口让你选择游戏程序，
选一次就记住了。

工具靠游戏程序的 SHA-256 识别版本，只认上表两个构建：所有功能都依赖这两个版本的内存地址，换了版本地址就对不上。
选到不支持的程序会弹窗提示，并显示它的 SHA-256；想支持那个版本的话，把这串值发给作者。
地址表见 `MAP.md`（特别版）和 `MAP_DX9.md`（原版）。

## 二、启动

1. 双击 `start_game.bat`。它启动游戏并把工具挂上，游戏仍由你操作。
   - **选哪个版本**：已经开着某个版本的游戏，就用那个；两个都开着，用前台那个；都没开而且两个都装了，
     会弹窗让你点“原版 DX9”或“特别版”，下次默认选上次的。
   - 原版会直接按 DX9 启动，不弹 Steam 的 DX9/DX10 选择框。
   - 一定要用它启动：这样后退才快。游戏已经开着时它只会挂上去，后退会慢很多。
2. 照常玩到想练的房间（要能操作角色，不能在菜单、读盘、过场里）。
   - 原版只能在**标题画面或战斗房间**里接管、存快照；任务选择等菜单里不行。
3. 双击 `tas_player.bat` 打开播放器。会出现两个窗口：
   - **主窗口**：录制、接管、走帧、练习辅助、状态面板。
   - **输入脚本窗口**：一行一帧的脚本。关掉只是隐藏，主窗口的“脚本窗口”按钮能再叫出来。

切到别的窗口时，游戏会原地冻结，切回去继续。

## 三、基本流程

### 录一段再改

1. 按“● 录制”（或小键盘 `*`），点回游戏窗口照常操作。录制期间游戏没有声音。
2. 再按一次停止。按过的键逐帧出现在脚本窗口里。
3. 用后退、前进看每一帧，直接改脚本里的行。改了已经放过的行，游戏会自动退回去重放。
4. 按“▶ 播放”（或小键盘 `/`）看整段效果。

### 从零手写

1. 按“⏸ 接管”，游戏停在这一帧，它就是第 0 帧。
2. 在脚本窗口里一行一行写键名，按小键盘 `+` 一帧一帧走。

### 结束

按“⏵ 交还操作”，游戏回到你手里。做过后退的话，游戏会先回到接管（或上一次录制结束）的那一刻再交还，
这是为了让声音能安全恢复。

## 四、按键

| 按键 | 作用 | 哪里有效 |
|---|---|---|
| 小键盘 `*` | 开始 / 停止录制 | 任何窗口 |
| 小键盘 `/` | 播放 / 暂停 | 任何窗口 |
| 小键盘 `+` | 前进一帧 | 任何窗口 |
| 小键盘 `-` | 后退一帧 | 任何窗口 |
| `←` `→` | 前后一帧 | 主窗口 |
| `Shift` + `←` `→` | 前后十帧 | 主窗口 |
| 空格 | 播放 / 暂停 | 主窗口 |
| `Home` | 回到第 0 帧 | 主窗口 |
| `F1` `F2` `F3` `F5` `F6` | 练习辅助开关 | 游戏窗口在前台时 |
| `Ctrl+Shift+↑/↓` | 连着的行里同一个键全选 | 脚本窗口 |

## 五、脚本窗口

- **一行就是一帧**，左边是帧号。`S W` 表示这一帧同时按 S 和 W；空行表示这一帧不按键。
- 写 `5 S` 再换行，会自动列成 5 行 `S`。`#` 后面是注释。
- **双击帧号**，或在“跳到”里填帧号回车，游戏直接跳到那一帧。上面还有一条进度条可以拖。
- **折叠相同行**：连着 3 行以上相同的行会折成一行，点左边的三角展开。
- **同键全选**：光标放在一个键上，按“↑ / ↓ 同键全选”，连着的行里这个键一起选中，可以一起删或改。
- 脚本存在 `runs\` 里，边改边自动保存。
- **播放、走帧用的是脚本窗口里打开的那份脚本**。要看别的脚本（比如示例），先在脚本窗口里点“打开…”选它，
  否则按播放时放的还是窗口里原来那份。

完整的脚本写法见 `SCRIPT.md`。示例脚本在 `runs\`：`dx9-exceed-demo.tas` 是原版血宫里 11 次“EX 飞燕命中后一帧 JC、
红刀保留”的连段，文件开头写了需要的起始位置。

## 六、右边一栏能看到什么

走过的帧才有内容，改了前面的输入后要重新走一遍才更新。

- **动画**：`动画771  14/86` 表示这一帧是 771 号动画的第 14 帧，这段动画共 86 帧。
- **红刀点**（尼禄，目前只在特别版显示）：
  - 金色“MAX点”：把油门键写在这一行，红刀槽直接充满 3 格。
  - 红色“红刀点”：把油门键写在这一行，+1 格。
  - “★MAX成功 / ★红刀成功”：这一行的油门键已经生效。
  - 窗口长度会随命中停顿和游戏速度变化，所以没有固定帧数表，以实际走出来的标记为准。

主窗口的状态面板显示当前帧的按键、动作、动画、位置、生命、红刀槽，以及每个敌人的距离和能不能踩。

## 七、练习辅助

| 开关 | 作用 |
|---|---|
| F1 锁血 | 自己和敌人的血都锁在满值 |
| F2 无限魔力 | 魔人槽保持满 |
| F3 时间不减 | 血宫倒计时不走 |
| F5 一击必杀 | 敌人的血保持在 1（和锁血同开时以它为准） |
| F6 踩头方框 | 在游戏画面上标出敌人身上能踩的点 |

踩头方框的颜色：

- **红**：这一帧按跳就能踩到。
- **黄**：位置够得着，但现在不能踩（站在地上、刚起跳的头几帧、冷却没结束）。
- **绿**：够不着。

逐帧步进时颜色是准确的；实时游玩时可能慢一帧左右。

两个版本都有这五个开关。原版的一击必杀覆盖 14 种普通敌人，Boss 和剧情里不能杀的单位会跳过；
没覆盖到的敌人，播放器会显示它的类名。原版踩头方框的位置已经和游戏画面核对过，颜色变化还没在实战里逐帧核对。

## 八、播放时的声音

接管期间游戏默认没有声音。脚本窗口里勾上“带音效”后按播放：

- 从时间线第 1 帧开始按游戏速度播放，有打击声、人声等音效。
- 放完或中途暂停后，游戏回到无声状态，停在放到的那一帧。
- 交还操作后背景音乐恢复。
- **原版**：游戏窗口不在前台时，系统会把它的声音静音（DirectSound 的规则）。播放器开始带音效播放时会自动把游戏切到前台，
  播放期间别再点别的窗口。
- **特别版**：带音效播放用到的声音保护默认关闭（它和“后退后交还操作”的崩溃有关，修好之前先停用），
  所以这个选项通常是灰的。播放时没有背景音乐。

## 九、存档与读档

脚本窗口里的“存档”把当前这一帧记下来并起个名字；“读档 ▾”列出所有存档，点一个，游戏就回到那一帧。

- 存的是“这份脚本的第几帧”。读档后脚本窗口打开的还是那份脚本，帧号不变，往前可以一直退到第 0 帧，
  那一帧之后的行可以接着改。
- 交还操作、自己玩一会儿、再接管之后，存档还能读。这时读档要先等游戏里正在放的声音放完，可能要几秒。
- 读档得到的时间线不能“带音效播放”。
- 交还操作时，游戏回到的是这次接管的那一刻，不是存档那一帧。
- 存档是游戏内存的快照，只在**这一次游戏运行、这个房间没有重新读盘**时有效。换房间、读盘、
  从检查点重来、关游戏或重启工具之后，存档全部失效（脚本文件还在）。
- 最多 12 个；不用的在“读档 ▾ → 删除存档”里删掉。存档期间游戏不会回收显卡资源，留着存档连续玩很久的话，
  工具会主动放弃存档，避免资源表写满。

## 十、已知限制

- **原版不要把游戏窗口最小化。** 最小化时 D3D9 会丢失显卡设备，工具为了安全会清掉所有快照、把操作交还给你，
  当前时间线就没了（脚本文件还在）。被别的窗口挡住没关系。
- 原版“后退之后交还操作”还没测过（特别版在这种情况下崩溃过），做过后退的话，结束时直接关游戏最稳妥。
- 时间线不能跨读盘。走到门或读盘的地方，工具会停下；后退几帧，或交还操作后自己走过去。
- 做过后退之后不能直接卸下工具，要先交还操作。
- 录制时用鼠标转的视角不会被记下来，重放结果可能和录的时候不一样。
- 重启工具的后台服务会丢掉当前时间线（脚本文件还在，但起点状态没了）。
- 和其他修改器一起用可能冲突，本工具自带的练习辅助不需要别的修改器。
- 其他剑招的红刀点、非加速模式都没有单独验证过。

## 十一、出问题时

- **游戏崩溃**：崩溃位置记在 `%LOCALAPPDATA%\DMC4TAS\exception.log`，后台服务的错误在 `logs\tas-service.err.txt`。
- **开始录制没反应**：提示“游戏没能停在帧闸上”时再按一次。
- **播放器连不上游戏**：确认游戏开着，并且是用 `start_game.bat` 启动的。
- **重启过后台服务后播放器没反应**：关掉播放器的两个窗口，重新双击 `tas_player.bat`（旧窗口还连着已经关掉的服务）。
- **启动时提示“写入监视没有全部打开”**：后退会用较慢的方式，功能不受影响。
