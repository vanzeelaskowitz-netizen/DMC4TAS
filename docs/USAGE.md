# DMC4TAS 使用教程

《鬼泣4》PC Steam 版的逐帧 TAS 工具：一帧一帧地写输入、单帧前进、后退重写，做法类似 Celeste Studio。
只用于单机游玩，不改游戏文件和存档。English version: [USAGE_EN.md](USAGE_EN.md)

**怎么读这份教程**：第一次用，按顺序读完“一、准备”到“五、手把手教程”的教程 1 和教程 2 就能上手；
其余章节用到时再查。脚本的完整写法在 [SCRIPT.md](SCRIPT.md)。

---

## 零、支持的版本和功能

| 版本 | Steam 应用 | 程序 | 构建号 |
|---|---|---|---|
| 特别版 | 329050 | `DevilMayCry4SpecialEdition.exe` | 24329835 |
| 原版（DX9） | 45700 | `DevilMayCry4_DX9.exe` | 21360 |

原版目录里的 `DevilMayCry4_DX10.exe` 不支持。两个版本用同一套工具、同一个播放器，工具按游戏程序自动选择。

| 功能 | 特别版 | 原版（DX9） |
|---|---|---|
| 逐帧前进、后退、改脚本、播放 | ✓ | ✓ |
| 录制键盘操作 | ✓ | ✓ |
| 手柄输入（录制和脚本） | — | ✓（脚本播放测过；用真手柄录制还没测） |
| 存档 / 读档 | ✓（在游戏里测得还不多） | ✓（在游戏里测得还不多） |
| 练习辅助 F1 F2 F3 F5 | ✓ | ✓（敌人锁血和一击必杀只覆盖 14 种普通敌人） |
| F6 踩头方框 | ✓ | ✓（颜色变化还没在实战里逐帧核对） |
| 红刀点（尼禄 Exceed）标记 | ✓ | ✓ |
| 播放时带游戏音效 | 默认不可用（见第九节） | ✓，从当前帧开始，没有背景音乐 |
| TAS 帧率 | 固定 60 | 跟游戏的 Frame Rate 设置走（见第十一节） |
| 自己玩的时候切到别的窗口 | 游戏原地冻结 | 游戏照常运行 |

## 一、准备（只做一次）

### 1. 游戏

- 正版 Steam 版，Steam 要开着并登录。
- 游戏必须是**窗口模式**。工具会让游戏停在某一帧等你，全屏的游戏冻住时会盖住整个屏幕，电脑就没法用了，
  所以全屏时工具不会冻结游戏。
  - 特别版：游戏里 Options → PC Settings → Full Screen 设成 OFF。
  - 原版：用记事本打开 `%LOCALAPPDATA%\CAPCOM\DEVILMAYCRY4\config.ini`（先复制一份备份），
    把 `FullScreen=ON` 改成 `FullScreen=OFF`。
- 不要同时开别的修改器。工具自带锁血、无限魔力等练习辅助（第八节），别的修改器改过的数值也不会写进脚本，
  重放会对不上。

### 2. Python

到 [python.org](https://www.python.org/downloads/) 安装 Python 3.13（64 位）。安装时保留勾选“py launcher”。

### 3. 下载工具

在 GitHub 页面点 **Code → Download ZIP**，解压到任意文件夹（会用 git 的话 `git clone` 也行）。

### 4. 安装组件

双击 `setup.bat`。它会在工具文件夹里建一个 `.venv` 文件夹，装好需要的组件（需要联网，几分钟）。
看到“安装完成”就好了；失败的话把窗口里的报错发给作者。只用做一次，以后更新工具时如果
`requirements.txt` 变了，再双击一次。

### 5. 记下你的键位

**脚本里写的是键盘上的键，不是游戏里的动作。** 先在游戏的按键设置里看好每个动作对应哪个键，后面写脚本时要用。
仓库里的示例脚本和本教程用的是作者的这套键位，想直接用示例，最简单的办法是把游戏键位改成一样的：

| 动作 | 特别版 | 原版 |
|---|---|---|
| 锁定 | `Space` | `Space` |
| 近战（剑） | `J` | `J` |
| 跳 | `K` | `K` |
| 射击 | `L` | `L` |
| 恶魔之手（尼禄） | `I` | `RightAlt` |
| 油门 Exceed（尼禄） | `Q` | `Q` |
| 移动 | `W` `A` `S` `D` | `W` `A` `S` `D` |
| 左右转视角 | `LeftShift`、`F` | `LeftShift`、`F` |

移动方向是**相对镜头**的：`W` 是画面里的“往前”，不是固定朝某个敌人。

**视角最好也绑在键盘上。** 录制只记键盘（原版还有手柄），用鼠标转的视角不会记下来，重放时镜头方向不同，
同样的 `W` 就会往别的方向走。

特别版的 Turbo（Game Options 里）会改变游戏速度。同一份脚本在 Turbo 开和关时打出来不一样，
做脚本和放脚本时保持同一个设置。本仓库的示例和教程里的帧数都是 Turbo 开着测的。

## 二、每次启动

### 1. 双击 `start_game.bat`

1. **选语言**：按 `1` 英文、`2` 中文。5 秒不按就沿用上次的选择（存在 `language.txt`）。
   播放器、脚本窗口、提示信息都用这个语言。
2. **选版本**（自动）：
   - 已经开着某个版本的游戏，就用那个；两个都开着，会弹窗让你选。
   - 都没开，只装了一个，就启动那个；两个都装了，会弹窗让你点“原版 DX9”或“特别版”，下次默认选上次的。
   - 原版会直接按 DX9 启动，不弹 Steam 的 DX9/DX10 选择框。
3. **找游戏**：从 Steam 里自动找。找不到（比如游戏放在别的文件夹）会弹窗让你选游戏程序，选一次就记住了
   （`game_path.txt` / `game_path_dx9.txt`）。工具用 SHA-256 认版本，选到不支持的程序会弹窗显示它的 SHA-256，
   想支持那个版本就把这串值发给作者。
4. 黑窗口最后显示“**工具已挂上，游戏由你操作。**”就成功了，这个黑窗口按任意键关掉即可，工具在后台运行。

**一定要用 `start_game.bat` 启动游戏。** 这样工具能在游戏启动的一瞬间打开“写入监视”，后退一次只要约 0.02 秒。
游戏已经开着时它只会挂上去，后退每次约 0.2 秒，功能不变。启动时如果提示“写入监视没有全部打开”，意思一样：只是慢一点。

### 2. 走到想练的地方

照常玩，走到想练的房间。能接管的地方：

- 特别版：任何能操作角色的房间（不能在菜单、读盘、过场里）。
- 原版：**标题画面或战斗房间**。任务选择之类的菜单里不行。

练连段推荐血宫（Bloody Palace）第 1 层的稻草人：敌人弱，打不死你。配合 F1 锁血、F3 时间不减（第八节），
就不怕倒计时把你踢出去。

自己玩的时候切到别的窗口：特别版的游戏会原地冻结（不弹暂停菜单），切回去继续；原版不冻结，照常运行，
别让角色站在敌人旁边挨打。

### 3. 双击 `tas_player.bat`

会出现两个总在最上层的窗口：**主窗口**“DMC4 逐帧播放器”和**脚本窗口**“DMC4 输入脚本”。
主窗口标题后面写着现在是哪个版本、TAS 按多少帧率跑，例如“DMC4 逐帧播放器 · 原版 DX9 · 60 帧”。

脚本窗口关掉只是隐藏，主窗口的“脚本窗口”按钮能再叫出来。关掉主窗口才是关播放器；关播放器不会关游戏，
也不会卸下工具。**接管着的时候关掉播放器，游戏会一直停在那一帧**（后台服务还握着它）：重新双击 `tas_player.bat`，
按“⏵ 交还操作”就好。

## 三、先懂几个概念

- **接管**：按“⏸ 接管”，游戏停在当前这一帧，工具接过输入。这一刻叫**第 0 帧**，从这里开始的一段叫**时间线**。
- **一行一帧**：脚本第 1 行是第 1 帧的输入，第 2 行是第 2 帧，以此类推。画面显示“第 N 帧”，意思是前 N 行已经执行完。
- **前进**：执行下一行。**后退**：把游戏内存恢复到前一帧的样子（读快照），不是倒放。
  后退之后改输入，之后的帧就按新脚本重新算。
- **改了已经放过的行**，游戏会自动退回到改动的地方，按新脚本重放到你所在的那一帧，画面随即更新。
- **恢复**：后退、改了已经放过的行、⏮ 回起点、拖进度条或双击帧号往回跳、读档，都是把游戏内存恢复成快照。
  下面几节说的“做过恢复”就是指这些，不只是按 ◀。
- **交还操作**：时间线结束，游戏回到你手里。脚本文件留着，下次接管从第 1 行重新开始。
- **接管期间游戏没有声音**。这是恢复能安全进行的前提；想听声音见第九节。
- **时间线不能跨读盘**。走到门口、读盘的地方时：
  - 还没做过恢复：时间线自动结束，游戏交还给你，照常读盘过去（存档会失效）。
  - 做过恢复：工具停在读盘前。后退几帧，或交还操作后自己走过去。
- 脚本只记按键，**不记位置**。同一份脚本要从同样的位置、同样的镜头方向、同样的敌人状态开始，才能打出同样的结果。

## 四、界面一览

### 主窗口“DMC4 逐帧播放器”

从上到下：

1. **● 录制**：开始 / 停止录制你的键盘操作（小键盘 `*` 也行）。
   **录完重放核对**：勾上后，停止录制时会从这次录制开始的那一帧重放一遍，检查结果是否和录的时候一样（花的时间和录的一样长）。默认不勾。
   **⏸ 接管 / ⏵ 交还操作**：同一个按钮，接管后变成交还。
   **脚本窗口**：把脚本窗口叫出来。
2. **⏮ 起点**（回第 0 帧）、**◀ 10**、**◀ 1**、**▶ 播放**、**1 ▶**、**10 ▶**。
3. **练习辅助**：F1 锁血（我方+敌人）、F2 无限魔力、F3 时间不减、F5 一击必杀、F6 踩头方框。
   按下去变绿就是开着。开着 F1 或 F5 时，下面还有一行“敌人覆盖 n/m”，原版还会写出跳过了哪些敌人。
4. **进度条**：拖动跳到某一帧。
5. **状态面板**：当前帧的详细状态（下面细说）。
6. 最下面：操作提示，以及一行状态消息。出错时那一行会变色，先看它。

#### 状态面板怎么读

顶部大字“第 N 帧 / 总帧数”。没有接管时显示“你在操作游戏”。

特别版：

| 行 | 意思 |
|---|---|
| 键盘按住 | 这一帧脚本按住的键 |
| 角色读到 | 游戏角色实际读到的：按住 / 按下（刚按）/ 松开 的按钮，以及方向。和上一行对不上，说明游戏没读到你的键 |
| 动作 动画 @ 帧 | 角色当前的动作号、动画号和动画里的第几帧；后面是地面 / 空中、踩敌冷却、生命 |
| 红刀 | 尼禄的红刀槽和这一帧是不是红刀点（第五节教程 3） |
| 位置 | 坐标和这一帧移动了多少 |
| 命中停顿中 | 打中东西后的停顿还剩多少 |
| 敌人1 … | 按距离排序的每个敌人：类型、生命、距离、是否在踩敌球内、能不能踩。能踩的那行是绿的 |
| ★ 这一帧触发了 Enemy Step | 这一帧踩到了敌人 |

原版：第一行同样是“键盘按住”，然后是场景类名和这一帧的时间单位；动作、动画、角色输入更新次数、生命；红刀；位置；
以及每个敌人的类型、生命、动作、距离。原版没有“角色读到”这一行。

如果出现“**角色这一帧没有读输入**”，多半是游戏自己的暂停画面开着：在脚本里写一行 `Escape` 走一帧就能关掉。

### 脚本窗口“DMC4 输入脚本”

1. **新建**、**打开…**、**另存为…**；**↑ 同键全选**、**↓ 同键全选**；右边是“**播放带音效**”勾选框。
2. **⏮**、**◀ 1**、**▶ 播放**、**1 ▶**；“**跳到** [ ] 帧”输入框。
3. **存档**、**读档 ▾**（第五节教程 5）。
4. 进度条和当前帧号。
5. 文件名行：`script-20261125-101500.tas　共 120 帧　（自动保存）`。有 ⚠ 时说明这份脚本录制时的帧率和现在不同（第十一节）。
6. **编辑区**：左边一栏是帧号，中间是脚本，右边一栏是那一帧的动画和红刀点。蓝底的一行是画面当前这一帧用的输入。
7. 最下面是写法提示和错误说明。写错的行标红，改好之前游戏继续用上一版脚本。

`.tas` 文件可以直接从资源管理器拖进脚本窗口打开。

## 五、手把手教程

### 教程 1：录一段，改一帧（5 分钟）

目标：学会录制、回放、改脚本。

1. 按第二节启动，进到一个有敌人的房间，打开播放器。
2. 按 **● 录制**（或小键盘 `*`）。状态行显示“开始录制”。
3. 点一下游戏窗口，照常操作几秒：锁定敌人、砍几刀、跳一下。录制期间没有声音；切到别的窗口时游戏冻结，那段不算进录制。
4. 再按小键盘 `*` 停止。你按过的键逐帧出现在脚本窗口里，文件存成 `runs\take-<时间>.tas`。
5. 按 **⏮**（回第 0 帧），再按 **▶ 播放**（或小键盘 `/`）：游戏按脚本把刚才那段重放一遍，放到最后一行停住。
6. 找一行有 `J` 的（挥砍）。把这一行的 `J` 删掉，在往下第 5 行加上 `J`。
   游戏会自动退回改动的地方重放，右边一栏的动画号在新的位置出现。按 **⏮** 再播放，看效果。
7. 满意了按“**⏵ 交还操作**”，游戏回到你手里。

小提示：

- 想一次删掉一段里所有的 `J`：光标放在任意一个 `J` 上，按 `Ctrl+Shift+↑` 或 `↓`（或按钮“同键全选”），
  连着的行里的 `J` 全被选中，按 `Delete` 删掉，或直接打字替换。

### 教程 2：从零手写一个踩敌跳（Enemy Step / JC）

目标：学会接管、逐帧走、看踩头方框、在准确的那一帧按跳。

1. 站到一个敌人旁边，贴近一点。打开 F1 锁血（血宫再开 F3 时间不减）。
2. 按“**⏸ 接管**”。状态行显示“已接管，游戏停在帧闸上。这里是第 0 帧……”。
3. 在脚本窗口点“新建”，写：

   ```
   5 Space
   Space K
   40 Space
   ```

   光标离开一行后，带数字的行会自动展开：先按住锁定 5 帧，第 6 帧同时按跳，之后 40 帧继续按住锁定。
4. 按小键盘 `+` 一帧一帧走（或按 **1 ▶**）。走过第 6 帧，角色起跳。
5. 打开 **F6 踩头方框**。敌人身上出现方框：
   - **红**：这一帧按跳就能踩到。
   - **黄**：够得着，但现在还不能踩（刚起跳的头几帧、冷却没结束、站在地上）。
   - **绿**：够不着。
6. 继续按 `+` 往前走。走到方框第一次变**红**的那一帧，把**这一行**（画面当前这一帧，蓝底的那行）的 `Space` 改成 `Space K`。
7. 游戏会自动退回去，带着这个 `K` 把这一帧重新走一遍，不用再按 `+`。主窗口状态面板出现“**★ 这一帧触发了 Enemy Step**”，
   右边一栏这一行变成新的动画（特别版是 17 号），就是踩到了。
8. 没踩到？把 `K` 挪到前一行或后一行再试。改一行、看一眼，这就是 TAS 的基本节奏。
9. 方框一直是绿的，说明跳起来也够不着：站得更近一点重新接管，或者在起跳那一行加上朝敌人的方向键（例如 `Space W K`）。

踩敌之后的头 8 帧左右按攻击会被吞掉（60 帧时测的），要稍等几帧再出招，具体以逐帧走出来的为准。

### 教程 3：红刀点（尼禄 Exceed）

目标：用右边一栏的标记，把油门按在准确的那一帧。

1. 接管，写几行空行再写一行 `J`（挥砍），往后走 30 帧左右。
2. 右边一栏会在挥砍的某几帧标出：
   - 金色“**MAX点**”：把油门键（示例里是 `Q`）写在这一行，红刀槽直接充满 3 格。
   - 红色“**红刀点**”：写在这一行，+1 格。
3. 在金色那一行加上 `Q`（只写这一行，前一行不要有 `Q`）。游戏重放后，这一行显示“**★MAX成功**”，状态面板里红刀槽变成 3。

红刀窗口的长短会随命中停顿和游戏速度变化，所以没有固定的帧数表，**以实际走出来的标记为准**。
标记只出现在走过的帧上；改了前面的输入，要重新走一遍才更新。

### 教程 4：用示例脚本

1. 在脚本窗口点“**打开…**”，选 `runs\` 里的示例（或直接拖进窗口）。
2. 摆好起始位置，接管，按 **▶ 播放**。只有 `dx9-exceed-demo.tas` 在开头注释里写了起始位置；其他示例没有，
   站到一个敌人旁边（特别版可以用血宫的稻草人）试就行，打出来的结果会和作者的不一样。

**播放、走帧用的永远是脚本窗口里打开的那份脚本。** 想放示例，一定要先在脚本窗口里打开它。

**打开的文件改动会直接存回那个文件**，示例也一样；旧写法的文件（`sample.tas`、`demo.tas`）第一次改动时会被改写成一行一帧。
想保留原样，先点“**另存为…**”存一份再改。

| 文件 | 版本 | 内容 |
|---|---|---|
| `sample.tas` | 特别版 | 8 帧的小例子（旧的“帧号: 键”写法） |
| `demo.tas` | 特别版 | 锁定前进 200 帧，然后挥砍、跳 |
| `streak-example.tas` | 特别版 | 后进斩（Streak）：锁定、后、前+挥砍，第 12 帧出 792 号动画往前冲 |
| `fight-probe.tas` | 特别版 | 血宫里约 500 帧的实战输入，开发时用来测试后退 |
| `dx9-exceed-demo.tas` | 原版 | 血宫稻草人，11 次“EX 飞燕命中后一帧 JC、红刀保留”的连段；开头注释写了起始位置（尼禄站在稻草人右边约 350 远） |

示例只有在起始位置、镜头、键位都一样时才会打出一样的结果（第三节）。

### 教程 5：存档和读档

脚本窗口里的“**存档**”把当前这一帧记下来并起个名字；“**读档 ▾**”列出所有存档，点一个，游戏就回到那一帧。

- 存的是“这份脚本的第几帧”。读档后脚本窗口打开的还是那份脚本，帧号不变，往前可以一直退到第 0 帧，那一帧之后的行可以接着改。
- 交还操作、自己玩一会儿、再接管之后，存档还能读。特别版这时读档要先等游戏里正在放的声音放完，可能要几秒；
  声音一直停不下来时会拒绝读档，过一会儿再试。原版直接读。
- 读档得到的时间线不能“带音效播放”。
- 交还操作时，游戏回到的是这次接管的那一刻，不是存档那一帧。
- 存档是游戏内存的快照，只在**这一次游戏运行、这个房间没有重新读盘**时有效。换房间、读盘、从检查点重来、
  关游戏或重启工具之后，存档全部失效（脚本文件还在）。
- 最多 12 个；不用的在“读档 ▾ → 删除存档”里删掉。存档期间游戏不会回收显卡资源，留着存档连续玩很久的话，
  工具会主动放弃存档，避免资源表写满。

### 教程 6（原版）：用手柄

原版可以在脚本里写手柄输入，也可以用手柄录制。写法：

```
PadRB                  # 锁定
PadRB PadLS=0/1        # 锁定，左摇杆推满向上
PadRB PadLS=0/1 PadY   # 锁定、推上、挥砍（默认键位 Y 是剑）
PadLT                  # 左扳机按到底
```

`#` 后面是注释，这几行可以直接粘进脚本。用手柄的脚本播放在游戏里测过；插着真手柄录制还没测过。

- 按键 `PadA` `PadB` `PadX` `PadY` `PadLB` `PadRB` `PadBack` `PadStart` `PadL3` `PadR3`，十字键 `PadUp` `PadDown` `PadLeft` `PadRight`。
- 摇杆 `PadLS=x/y`、`PadRS=x/y`：x 向右、y 向上，范围 −1 到 1。扳机 `PadLT`、`PadRT`，`PadLT=0.5` 是按一半。
- 键盘和手柄的键可以写在同一行。播放时一行里没写手柄，就当手柄全松开，插着手柄误碰也不会混进去。
- 用手柄录制时，摇杆值会保留游戏里的精确数值。

详见 [SCRIPT.md](SCRIPT.md) 的“手柄”一节。

## 六、按键速查

| 按键 | 作用 | 在哪里有效 |
|---|---|---|
| 小键盘 `*` | 开始 / 停止录制 | 任何窗口（播放器开着时） |
| 小键盘 `/` | 播放 / 暂停 | 任何窗口 |
| 小键盘 `+` | 前进一帧 | 任何窗口 |
| 小键盘 `-` | 后退一帧 | 任何窗口 |
| `←` `→` | 前后一帧 | 主窗口 |
| `Shift` + `←` `→` | 前后十帧 | 主窗口 |
| 空格 | 播放 / 暂停 | 主窗口 |
| `Home` | 回到第 0 帧 | 主窗口 |
| `F1` `F2` `F3` `F5` `F6` | 练习辅助开关 | 播放器开着、游戏窗口在前台时（录制中 F1–F5 不响应） |

| 双击帧号 | 跳到那一帧 | 脚本窗口 |

## 七、脚本写法速览

```
# 这一整行是注释，不占帧
S W          # 第 1 帧：同时按住 S 和 W
S W          # 第 2 帧：继续按住
J            # 第 3 帧：只按 J

5 K          # 上面的空行是第 4 帧（什么都不按）；这一行展开成第 5–9 帧的 5 行 K
```

- 键名用空格或逗号隔开，不分大小写。一个键要按住几帧，就连着几行都写它；哪一行没写，那一帧就松开。
- `#` 后面是注释，可以单独一行，也可以写在一行键名的后面。
- 要按数字键时写成 `1 5`（1 帧，按 5）。
- 想直接写到后面某一帧：在最后一行下面的空白处，点那一帧所在的高度，光标落到那一帧，中间自动补空行。
  左边帧号要双击才让游戏跳到那一帧。
- 新建的脚本存在 `runs\` 里；打开的文件改动直接存回原文件。改动停 0.4 秒后生效。

完整说明（键名列表、旧写法、文件格式）见 [SCRIPT.md](SCRIPT.md)。

### 播放的规则

- 按“▶ 播放”：从当前帧按脚本以正常速度放到最后一行，然后停住。播放中再按一次是暂停。
- 放完再按播放：回到第 0 帧，从头重放。
- 放完往下接着写：再按播放就从停住的地方接着放新写的部分。
- 脚本是空的时候，播放就是让游戏一直跑。

### 接管期间录制

- 做过恢复（后退、读档、改了放过的行、往回跳）之后按录制，会**从当前帧接着录**：停止后，脚本是前面那些帧加上这次录的。
  状态行会写“从第 N 帧接着录”。
- 只往前走过、没做过恢复时按录制，会从当前帧开始一条新的时间线，录制文件里只有这次录的部分。

## 八、练习辅助

| 开关 | 作用 |
|---|---|
| F1 锁血 | 自己和敌人的血都锁在满值 |
| F2 无限魔力 | 魔人槽保持满 |
| F3 时间不减 | 血宫倒计时（原版还有任务计时）不走 |
| F5 一击必杀 | 敌人的血保持在 1（和锁血同开时以它为准） |
| F6 踩头方框 | 在游戏画面上标出敌人身上能踩的点 |

- 可以点主窗口的按钮，也可以在游戏窗口在前台时按 F 键。F 键要播放器开着才有效（是播放器在读这几个键），
  录制期间 F1–F5 不响应。
- 踩头方框的颜色见教程 2。逐帧走时颜色是准确的；实时游玩时可能慢一帧左右。
- 原版的敌人锁血（F1）和一击必杀（F5）只覆盖 14 种普通敌人，Boss 和剧情里不能杀的单位会跳过；
  没覆盖到的敌人，主窗口会写出它的类名。
- 练习辅助改的数值不算输入。开着锁血做出的脚本，关掉锁血再放，可能因为敌人先死了而不同。

## 九、播放时的声音

接管期间游戏默认没有声音。脚本窗口里勾上“**播放带音效**”后按播放，就能听到打击声、人声等音效，**没有背景音乐**。

- **原版**：从当前帧开始按游戏速度播放（停在第 0 帧，或已经在脚本最后一行或更后面时，从第 1 帧开始）。
  系统会把不在前台的 DirectSound 程序静音，所以播放器开始带音效播放时会自动把游戏切到前台，播放期间别点别的窗口。
  从中间开始放时，前面无声帧里排队的声音可能会一下子响起来。
- **特别版**：从时间线第 1 帧开始放。但它需要的声音保护默认是关的（和“后退后交还操作”的崩溃有关，修好之前先停用），
  所以勾选框通常是灰的，写着“声音保护未启用”。
- 放完或中途暂停后，游戏回到无声状态，停在放到的那一帧。
- 交还操作后背景音乐恢复。

勾选框变灰时，括号里写着原因：

| 原因 | 意思 |
|---|---|
| 声音保护未启用 | 特别版默认如此 |
| 当前时间线未保护声音 | 这条时间线来自读档，或在声音保护打开之前开始。交还操作后重新接管 |
| 声音线程出错，重启游戏前没有声音 | 声音出过错，工具为了安全停用了声音，重启游戏后恢复 |

## 十、结束和交还

按“**⏵ 交还操作**”，游戏回到你手里，脚本留着。

做过恢复的话（后退、改了放过的行、⏮ 回起点、往回跳、读档都算，见第三节），交还时游戏会先回到“声音线程睡下的那一刻”——
也就是接管的那一帧，或者最近一次录制结束的那一帧——再交给你。原版做过带音效播放的话，这个位置是那次播放停下的那一帧。
这样声音才能恢复、过门才不会卡住。所以交还后角色可能回到了较早的位置，这是正常的。

## 十一、帧率（原版）

原版的 TAS 帧率跟着游戏设置里的 **Frame Rate** 走：

- `60 FPS MAX`：TAS 按 60 帧跑。
- `VARIABLE`：按显示器刷新率跑，例如 120 Hz 的显示器就是 120 帧。

主窗口标题会写出当前帧率。录制的脚本第一行写着录制时的帧率（例如 `# 120 fps`）；打开一份帧率和现在不同的脚本时，
文件名后面会出现“⚠ 这是 120 帧录的，游戏现在是 60 帧”。帧率不同，同样的行数代表的时间就不同，脚本不能通用。

本教程和示例里的帧数（例如“踩敌后头 8 帧左右攻击会被吞”“命中后一帧 JC”）都是 60 帧时测的，在 120 帧下大约要翻倍，
要以实际走出来的为准。想和别人分享脚本，建议用 `60 FPS MAX`。

特别版目前固定 60 帧。

## 十三、已知限制

- **原版不要把游戏窗口最小化。** 最小化时 D3D9 会丢失显卡设备，工具为了安全会清掉所有快照、把操作交还给你，
  当前时间线就没了（脚本文件还在）。被别的窗口挡住没关系。
- 原版“做过恢复之后交还操作”测得还不多（特别版在这种情况下崩溃过）。做过很多后退的话，结束时直接关游戏最稳妥。
- 时间线不能跨读盘。没做过恢复时，走到门口时间线自动结束、游戏照常读盘；做过恢复时工具停在读盘前，
  后退几帧，或交还操作后自己走过去。
- 做过恢复之后不能直接卸下工具，要先交还操作。
- 录制时用鼠标转的视角不会被记下来，重放结果可能和录的时候不一样。
- 重启工具的后台服务会丢掉当前时间线（脚本文件还在，但起点状态没了）。
- 和其他修改器一起用可能冲突。
- 只验证过尼禄的部分招式；其他角色、Boss 战、非加速模式测得很少。

## 十四、常见问题

**按小键盘没反应。** 小键盘热键只在播放器开着时有效，确认 `tas_player.bat` 打开了。同时开着两个播放器时，
后开的那个抢不到这组热键，只有点在它的主窗口里时小键盘才有效：关掉多余的那个。

**播放器连不上游戏。** 确认游戏开着，并且工具挂上了（再双击一次 `start_game.bat`，游戏已经在运行时它会说“工具也已经挂着”）。

**重启过后台服务后播放器没反应。** 关掉播放器的两个窗口，重新双击 `tas_player.bat`。

**开始录制时提示“游戏没能停在帧闸上”。** 再按一次。

**接管失败，提示暂停画面关不掉。** 切回游戏，手动关掉暂停画面再接管。

**重放和录的时候不一样。** 常见原因：用了鼠标转视角；起始位置或镜头不同；中途开关过练习辅助；
Turbo 或帧率设置变了；开着别的修改器。勾上“录完重放核对”可以在录完时马上检查。

**改了脚本，画面没变。** 看有没有标红的行（写错了，窗口底部有说明）；确认改的是脚本窗口里正在用的那份。

**走到门口停住了，提示“到切场景（读盘）的地方了”。** 时间线不能跨读盘，而这条时间线做过恢复，所以工具停在了读盘前。
后退几帧；要过门就交还操作后自己走过去。（没做过恢复时不会停：时间线自动结束，游戏照常读盘。）

**后退很慢。** 游戏不是用 `start_game.bat` 启动的。关掉游戏，再用 `start_game.bat` 启动。

**“播放带音效”是灰的。** 看括号里的原因，对照第九节的表。

**游戏崩溃了。** 崩溃位置在 `logs\game-exception.log`，后台服务的错误在 `logs\tas-service.err.txt`。
把这两个文件和你做了什么一起发给作者。重新双击 `start_game.bat` 即可继续，脚本文件都还在。
